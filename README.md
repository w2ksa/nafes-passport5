Nafes Passport is a gamified student progress platform designed to make learning more engaging, motivating, and fun. Built for Abha National Elementary School, it turns academic achievement into a space-themed journey where students earn points, unlock ranks, and collect silver, gold, and diamond stamps as they progress.
The platform includes a public student dashboard, a live leaderboard, and an admin panel for managing students, updating scores, importing data from Excel, and tracking changes in real time. With its clean interface, school-focused design, and motivation-driven experience, Nafes Passport helps teachers celebrate progress while keeping students excited to learn.
